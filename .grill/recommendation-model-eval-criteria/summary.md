## 2. 히스토리 (grill-me 질문과 사용자 답변, 순서대로)

> 범례
> - 번호가 붙은 본 항목(`1.`, `2.` …)은 Claude의 질문과 사용자의 답변이다.
> - 사용자가 곁가지로 물은 것은 그것이 나온 본 항목 아래에 `N-1`, `N-2`로 두고, `사용자 질문`과 `Claude 답변`으로 화자를 구분한다.
> - 곁가지가 있는 본 항목은 마지막에 `본 질문 최종 답변:`을 따로 적는다. 본 항목 번호는 곁가지가 생겨도 바꾸지 않는다.

### 시작: 사용자의 문제 제기

**1. 질문:** 새 평가 기준으로 어떤 결정을 내리려는가? (a. 모델 경로를 운영(`main`)에 올릴지 규칙 경로로 둘지 결정 / b. 최종 발표·보고서에서 모델 성능을 주장할 근거 / c. 앞으로 모델을 개선할 때 쓸 지속적인 측정 기준 / d. 그 밖의 것). Claude 추천은 a와 b 함께.

**2. 질문:** 모델을 다시 학습하거나 바꿔서 같은 기준으로 다시 잴 일이 실제로 있는가? ((i) 이번 발표·제출로 끝나고 모델은 더 안 바꾼다 / (ii) 발표 뒤에도 서비스를 이어 가며 모델 B 평가나 재학습을 할 수 있다 / (iii) 서비스 설문과 행동 로그가 쌓이면 새 데이터로 기준을 다시 보정할 계획이 있다). Claude 추천은 (i)에 가깝게 보고 c(지속 측정 기준)는 이번 범위에서 제외, 대신 재현 가능한 명령과 고정된 정의로 문서화.

**3. 질문:** 이번 기준에서 "성능"이 가리키는 것은 무엇인가? ((A) 모델이 실제 여행자의 다음 방문지를 맞히는 정도: Recall@10, 로그 정답 기준 / (B) 서비스 출력(3개 안 × 여러 날)이 쓸 만한 일정인가: 취향 일치, 거리, 다양성 등 일정 단위 지표 / (C) 모델이 있는 것이 모델 없는 것(규칙, 인기순)보다 나은가: 비교 우위). Claude 추천은 (C)를 최종 판정, (A)를 측정 도구, (B)를 안전선(전제 조건)으로.
- 답변: "추천대로 (C)가 최종 판정, (A)는 도구, (B)는 안전선으로 하겠습니다."
