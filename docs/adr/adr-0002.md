# ADR-0002: 그룹 취향 점수를 평균에서 표준편차 페널티를 뺀 값으로 통합

## Status

Accepted

1. Proposed: 2026-09-13
2. Accepted: 2026-09-21 (PR #14 머지)

## Context

**문제**

- 그룹원 각자가 15문항 5점 리커트 설문으로 취향을 입력하며, 카테고리별로 그룹 전체의 취향 점수를 하나로 통합해야 한다. 이 점수로 슬롯에 배치할 카테고리 순위를 정한다.
- 단순 합계나 평균은 "전원 3점으로 합의"와 "1점·5점으로 갈림"을 구분하지 못한다. 5점 리커트라 카테고리 간 동점도 쉽게 발생한다.
- 초기 설계안은 "평균이 같으면 분산이 작은 쪽, 그다음 동선이 짧은 쪽 순"의 타이브레이커 방식이었다. (설계 채팅)
- 채택한 공식은 평균에서 표준편차를 빼는 mean–risk 형태의 집계 방식이다.

**조건과 규모 (확인된 사실)**

- 그룹 구성원은 1~8명이다(`members` 최소 1명, 최대 8명). 설계 당시에는 최소 2명이었다.
- 표준편차의 최댓값은 점수 범위 4에서 인원수와 무관하게 2.0이다. (설계 채팅)
- 외부 데이터셋(Kaggle Travel Review Ratings)에서 국내 AI-Hub 여행로그 데이터를 사용하기로 했다. (사용자 진술)
- 정확성을 판단할 실제 사용자 응답 데이터는 없다.
- 가중치 0.5가 터무니없는 값이 아닌지 점검하기 위해, 실제 데이터 대신 무작위 점수 표본으로 시뮬레이션했다(그룹 200개 × 카테고리 24개, 그룹당 2~8명, 점수 1~5 무작위, seed 42). 설계 단계 시뮬레이션에서 문항 단위 점수의 표준편차는 약 0.9~1.6이었다. (설계 채팅)
  - 사후에 같은 조건으로 재현했을 때, 코드가 쓰는 값(멤버별 3문항 평균 간 표준편차)은 평균 0.67(5~95% 구간 0.27~1.09)이며, w=0.5의 페널티는 평균 0.34점, 최대 0.83점이다.
  - 점수 범위(1~5)의 폭은 4이므로 페널티는 범위의 약 8%이다. 페널티가 평균 차이를 압도해 순위를 뒤집는 크기(예: w=1이면 최대 약 1.7점)가 아니며, 개인 평균 점수의 최소 단위(1/3≈0.33점) 정도의 차이는 낼 수 있다.
  - 이 점검은 값이 비현실적이지 않은 범위인지 확인한 것이며, 최적값을 확인한 것은 아니다.

**범위와 책임 경계**

- 범위: 카테고리별 그룹 취향 점수의 산출 공식.
- 범위 밖: 점수를 쓰는 슬롯 구조와 장소 정렬(ADR-0000).

**가정 (확인되지 않음)**

- 이 공식은 참고 출처 없이 구현된 아이디어다. (사용자 진술)
- Proposed 날짜는 설계 문서에 공식이 처음 기록된 커밋 날짜(2026-09-13)다.

## Decision

우리는 그룹의 카테고리별 취향 점수를 구성원 개인 평균의 평균에서 모표준편차에 가중치 0.5를 곱한 값을 뺀 값(`평균 − 표준편차 × 0.5`)으로 통합한다.

- 구성원이 1명이면 표준편차를 0으로 처리한다.
- 동점을 풀기 위한 별도 타이브레이커(분산 2순위, 동선 3순위)는 두지 않는다.
- 가중치 0.5는 잠정값이다.

## Alternative / Considered Options

### 1. 단순 평균 / 백분율

- (장점) 구현이 가장 단순하다.
- (단점) 동점을 구분하지 못하고, 점수 분포를 보지 않는다. 백분율은 평균과 산술적으로 동일한 결과다.
- (소결) 기각.

### 2. 평균 + 분산 타이브레이커 (초기 설계안)

- (장점) 동점을 구분하고 점수 분포까지 본다.
- (단점) 평균이 같을 때만 분산이 작동하며, 동점 판정을 위한 별도 분기가 필요하다. 채택 후 재검토에서 G 대비 정확성 우위가 확인되지 않았다.
- (소결) 기각. 구현이 단순한 G로 대체했다.

### 3. 최댓값

- (장점) 확인되지 않음.
- (단점) 다수 의견을 무시하고 불공정 위험이 있다.
- (소결) 기각.

### 4. 최솟값

- (장점) 확인되지 않음.
- (단점) "한 명이라도 싫어하면 낮게"라 지나치게 보수적이며, 숫자 하나만 본다.
- (소결) 기각.

### 5. 중앙값

- (장점) 극단값의 영향이 적고, 동점 구분이 부분적으로 된다.
- (단점) 동점 구분이 부분적이다.
- (소결) 기각. 평가는 "중"으로 G보다 낮았다.

## Consequences

### Positive (Gain)

- 평균이 같아도 의견이 갈린 카테고리(예: [1, 5])의 점수가 합의된 카테고리(예: [3, 3])보다 낮아져 구분된다.
- 동점 처리를 별도 분기 없이 수식 하나로 해결해 구현이 단순하다.
- 점수 분포(편차)가 점수에 직접 반영된다.

### Negative (Loss)

- 이 방식이 다른 방식(초기 설계안 포함)보다 정확하다는 근거는 없다. 채택의 실질적 이유는 구현 단순성이다.
- 가중치 0.5는 잠정값이다. 무작위 가상 표본으로는 비현실적이지 않은 범위인지만 점검했고 최적값은 검증하지 않았으며, 실제 데이터 기반 보정은 이루어지지 않았다.
- 참고 출처 없이 구현된 공식이다.
- 점수가 같으면 여전히 동점이며, 순서는 무작위로 정해진다(ADR-0000 참조). 구성원이 1명이면 페널티가 없어 평균과 같다.
- 가중치가 `group_score.py`, `preference.py`, 테스트 도구(`generate_representative_surveys.py`)에 중복 정의되어 있어, 값을 바꿀 때 불일치할 수 있다. 계산에 쓰이는 것은 `group_score.py`의 값이다.
- 이 공식에 대한 단위 테스트가 저장소에 없다.

## Compliance / Reconsideration Conditions

**결정사항 반영 여부 검증 기준**

- [ ] 수동: 취향 점수 산출은 `group_score.py`의 `calculate_group_score`만 사용하고, 가중치 상수를 이 파일 한 곳에서만 정의한다. (현재는 중복 정의 상태)
- [ ] 자동(제안, 미구현): `calculate_group_score`의 단위 테스트를 추가한다. 동일 점수([3, 3])와 갈린 점수([1, 5])의 순위, 1명인 경우를 검증한다.
- [ ] 수동: 공식을 바꾸는 변경은 이 ADR을 대체하는 새 ADR을 먼저 작성한다.

**결정사항 반영 여부 측정 목록**

- [ ] 가중치 보정 결과 (실제 사용자 응답 데이터가 확보되면 측정. 현재 없음)
- [ ] 초기 설계안(평균 + 분산 타이브레이커)과의 정확성 비교 (현재 없음. 데이터 확보 시 재검토 조건)
