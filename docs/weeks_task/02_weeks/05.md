## 제출 항목

- 🚧 전체 데이터 흐름도(입력 -> 검색 -> 증강 -> 모델 응답/생성 결과)
- 🚧 사용 데이터/지식 소스 설명과 선택 이유(예: 이미지/영상 DB, 음성 데이터베이스, 텍스트 문서 등)
- 🚧 검색·임베딩·인덱싱 구현 내용과 모델 통합 방법(프롬프트 또는 입력 포맷)
- 🚧 컨텍스트 보강 도입 전후 예상 효과와 검증 계획, 혹은 도입이 불필요한 경우 그 이유
