# 포토미션 정답 판단 기준

verify 평가셋과 파인튜닝 학습 데이터에 사람이 정답(성공/재시도/실패)을 표시할 때 따르는 기준이다.
모델 비교와 개선 효과는 모두 이 정답으로 측정하므로, 표시하는 사람이 바뀌어도 같은 사진에 같은 정답이 나오도록 기준을 글로 정해 둔다.

## 1. 무엇을 판단하나

**"이 사진으로 미션을 했다고 인정할 수 있는가"**를 판단한다. 사진을 잘 찍었는지는 보지 않는다.

- **미션 문구가 기준이다.** "석가탑 돌 가까이 찍기"면 돌이 가까이 보여야 하고, 탑 전체가 나오지 않아도 된다.
- **랜드마크 미션은 그 장소 자체가 미션 대상이다.** 사진에 미션과 다른 장소가 보이면 실패다. 겉모습이 닮은 장소(월정교 사진에 동궁과월지 미션)도 마찬가지다.
- **일반 대상 미션은 대상만 본다.** 바다·커피처럼 사진만으로 어디인지 알 수 없는 미션은 어디서 찍었는지 추측하지 않고 미션 내용대로 찍혔는지만 본다.
- **위치 정보는 따로 고려하지 않는다.** verify는 사진 좌표가 제공될 때만 목표에서 5km 넘게 떨어진 사진을 먼저 걸러낸다. 좌표가 없는 사진이나 5km 안의 다른 장소는 사진만으로 판단하므로, 표시할 때도 사진에 보이는 것만 본다.

## 2. 세 등급

| 등급 | 기준 | 다시 찍으면 |
|---|---|---|
| 성공 | 미션이 요구한 대상(장소·물건·행동)이 사진에서 분명히 확인된다. 구도나 화질이 완벽할 필요는 없다 | 필요 없음 |
| 재시도 | 미션을 하려 한 것은 보이지만 핵심 대상이 제대로 보이지 않는다. 가려졌거나, 너무 작거나, 잘렸거나, 대상 대신 주변만 찍혔다 | 조금 바꿔 찍으면 성공할 수 있음 |
| 실패 | 핵심 대상이 아예 없거나, 미션과 관계없거나, 사진을 판단할 수 없다(스크린샷, 심한 흔들림, 지나치게 어두움) | 처음부터 다시 찍어야 함 |

헷갈리면 "이 사람이 같은 자리에서 한 발짝 움직이거나 각도만 바꾸면 성공할까?"를 묻는다. 그렇다면 재시도, 아니라면 실패다.

## 3. 자주 헷갈리는 경우

| 경우 | 판정 | 이유 |
|---|---|---|
| 글씨만 보임 (현판, 표지석, 간판, 메뉴판), 미션 대상은 안 보임 | 재시도 | 장소에는 왔지만 미션 대상을 찍지 않았다. 대상 쪽으로 돌아서 찍으면 성공할 수 있다 |
| 글씨와 미션 대상이 함께 보임 | 성공 | 대상이 보이면 글씨는 상관없다 |
| 미션 대상 자체가 간판·표지판임 ("가게 간판 찍기") | 성공 | 이때는 글씨가 곧 대상이다. 위의 "글씨만 보임" 규칙은 대상이 따로 있는 미션에만 적용한다 |
| 미션 대상은 보이지만 조건을 지키지 않음 ("헬멧 들고 찍기"인데 헬멧이 바닥에 놓여 있음) | 재시도 | 대상은 맞게 찍었고, 조건만 고쳐 다시 찍으면 성공할 수 있다 |
| 사람이 있어야 하는 조건 ("앉아서", "다 같이", "들고")인데 사진에 사람이 없음 | 재시도 | 이 조건은 사진 속 사람에게서 확인한다. 대상만 찍힌 사진은 조건을 확인할 수 없다 |
| "○○ 앞에서 찍기"인데 사람 없이 대상만 보임 | 성공 | "앞에서"는 대상 앞에서 카메라로 찍었다는 뜻으로도 읽히므로 대상이 보이면 인정한다 |
| "가까이" 미션에서 대상이 사진의 주인공이 아님 | 재시도 | 대상이 사진에서 가장 크게 나오거나 무늬·질감 같은 세부가 보이면 "가까이"를 지킨 것으로 본다 |
| 쇼핑 미션의 "물건·소품·기념품"인데 판매 상품이 아닌 조형물·장식만 보임 | 재시도 | 쇼핑 미션의 물건은 가게에서 파는 상품이나 산 물건을 말한다 |
| 사람이 대상을 일부 가리지만 대상을 알아볼 수 있음 | 성공 | 단체 여행 사진이라 사람이 함께 나오는 것이 자연스럽다 |
| 사람·나무·안내판이 대상의 핵심 특징을 가려 무엇인지 알아보기 어려움 | 재시도 | 가린 면적이 아니라 알아볼 수 있는지로 판단한다. 위치를 조금 옮기면 해결된다 |
| 대상이 멀리 작게 나왔지만 알아볼 수 있음 | 성공 | 미션이 "가까이"를 요구하면 재시도 |
| 대상이 점처럼 작아 알아보기 어려움 | 재시도 | |
| 대상의 일부만 나옴 (잘림) | 미션 문구에 따름 | "전경 담기"면 재시도, "가까이 찍기"면 성공 |
| 밤이나 역광이지만 대상의 윤곽이 보임 | 성공 | |
| 너무 어둡거나 흔들려 무엇인지 알 수 없음 | 실패 | 판단할 수 없는 사진이다 |
| 대상과 관계없는 사진 (셀카만, 음식만, 하늘만) | 실패 | |

## 4. 카테고리별 기준

| 카테고리 | 성공 예 | 재시도 예 | 실패 예 |
|---|---|---|---|
| 역사·문화 | 건물이나 유적이 미션대로 보임 | 입구나 현판만 보임, 대상이 가려짐 | 유적과 관계없는 사진 |
| 자연·힐링 | 미션이 말한 자연 요소(바다, 숲길, 폭포 등)가 보임 | 자연 요소가 작게 걸려 있고 사람이나 건물이 대부분 | 실내 사진, 자연 요소 없음 |
| 음식 | 미션이 말한 음식·음료가 보임 (먹던 중이어도 알아볼 수 있으면 됨) | 메뉴판·간판만 보임, 음식이 거의 가려짐 | 음식이 없음 |
| 액티비티 | 활동하는 모습, 또는 활동 장비·시설과 함께 찍음 | 시설 외관이나 입구만 보임 | 활동과 관계없는 사진 |
| 쇼핑·편의 | 미션이 말한 가게·거리·상품이 보임 | 간판만 보임 | 가게나 상품과 관계없는 사진 |

여러 명이 함께 찍는 미션(대표 1장)에서 미션이 인원을 정했다면 사진 속 인원도 확인한다.

## 5. 표시하는 방법

1. 미션 문구를 먼저 읽고 사진을 본다.
2. AI 점수는 보지 않는다. 점수를 보면 그쪽으로 끌려간다.
3. 한 번에 100장 이하로 나눠서 표시한다. 뒤로 갈수록 기준이 흔들린다.
4. 3초 넘게 고민한 사진은 `검토 필요`로 따로 표시하고 이유를 메모한다. 이 사진들은 다른 날 다시 보고 정답을 확정하며, 가능하면 다른 사람이 점수를 보지 않고 한 번 더 표시한다. 학습 데이터는 Pro 판정과 다른 사진도 다시 확인한다. 반복되는 유형은 이 문서의 기준에 추가한다.
5. 막히면 "3. 자주 헷갈리는 경우"를 다시 본다.
6. 미션 자체가 사진·장소와 맞지 않으면(장소를 짐작해 지어낸 미션, 사진을 잘못 읽고 쓴 미션) 실패로 표시하고 `검토 필요`에 이유를 적는다. 이 사진은 미션 품질 문제로 따로 센다.

## 6. 학습 데이터의 정답 만드는 순서

파인튜닝에는 등급만이 아니라 모델이 내야 하는 답 전체(`detected_labels`, `landmark_confidence`, `match_score`, `retry_hint`)가 필요하다. 판단은 사람이, 설명은 Pro가 맡고 사람이 확인한다.

**평가셋에는 이 절을 적용하지 않는다.** 평가셋 정답은 사람이 등급만 표시하며 Pro 결과를 보지 않는다. 평가셋 정답에 Pro가 섞이면 Pro와 비슷하게 답하는 모델이 유리해져 비교가 오염된다. 학습 데이터는 평가셋과 다른 여행(여행 ID)의 사진만 쓰므로 같은 사진이 두 곳에 들어가지 않는다.

1. 사람이 Pro 결과를 보지 않고 등급을 먼저 표시한다. 초안을 먼저 보면 Pro 판단에 끌려간다.
2. 같은 사진의 Pro 판정을 초안으로 보여 준다.
   - 등급이 같으면 초안을 확인하고 틀린 부분만 고친다.
   - 등급이 다르면 정답 등급을 주고 Pro에 이유와 다시 찍기 안내를 다시 쓰게 한 뒤, 그 초안을 확인한다.
3. `match_score`는 Pro가 낸 값을 쓴다. 사람이 점수를 직접 매기지 않으므로 사람마다 점수가 갈리지 않고, 등급 안에서의 차이(아슬아슬한 재시도와 거의 실패에 가까운 재시도)가 학습용 상대 난이도 정보로 남는다. 이 점수는 현재 등급 구간에 맞춘 값이라 임계값을 다시 정하는 데는 쓰지 않는다. 임계값은 평가셋의 사람 정답과 새 모델의 점수를 대조해 정한다. 다시 쓰게 한 값도 정답 등급의 점수 구간을 벗어나면 그 사진만 대표값(성공 95, 재시도 65, 실패 20)으로 바꾼다. 현재 구간은 성공 90 이상, 재시도 40 이상 90 미만, 실패 40 미만이다(`pipeline_verify.py`의 `SUCCESS_THRESHOLD`, `RETRY_THRESHOLD`). 자체 모델용으로 임계값을 다시 정하면 학습 데이터 점수도 새 구간에 맞춘다.
4. `landmark_confidence`는 사진에서 목표 장소 자체를 알아볼 수 있는 정도다. Pro 값을 쓴다. 랜드마크 미션에 한해, 사람이 "사진 속 장소가 목표 장소가 아니다"(닮은 다른 장소 등)라고 판단한 사진은 20 이하로 맞춘다. 목표 장소가 아닌데 높은 값을 배우면 닮은 장소를 통과시키는 쪽으로 학습된다. 바다·음식처럼 장소 자체를 알아보는 것이 핵심이 아닌 일반 대상 미션은 이 보정을 하지 않고 Pro 값을 그대로 쓴다.
5. 닮은 장소, 글씨만 보이는 사진, 대상이 가려진 사진처럼 모델이 자주 틀리는 유형을 의도적으로 포함한다.

## 7. 기준을 정한 배경

v1 평가셋(경주 랜드마크 200장)은 기준을 글로 정하기 전에 표시했다. Pro 판정과 정답이 엇갈린 25장을 다시 보니 두 유형이었다.

| 유형 | 건수 | 내용 | v1 정답 |
|---|---|---|---|
| 입구·현판만 찍힌 사진 | 5장 | 대릉원 정문과 현판, 고분은 안 보임. Pro는 90~95점 | 실패 |
| 대상이 가려지거나 잘린 사진 | 17장 | 사람·나무·안내판이 고분을 가리거나 일부만 나옴. Pro는 75~85점 | 재시도 |
| 그 외 | 3장 | 특정 고분 입구만 보이고 어두움 등 | 실패 |

같은 "글씨로만 장소를 알 수 있는 사진"인데 대릉원 표지석 사진은 성공, 정문 현판 사진은 실패로 갈렸다. 이 기준에서는 글씨만 보이는 사진을 재시도로 정했다. 장소에는 왔지만 미션 대상을 찍지 않은 경우라, "가려지거나 잘린 사진"과 같은 성격으로 본다.

이 기준으로 25장을 다시 표시하고, 바뀐 정답으로 v1 측정 결과를 다시 계산한다.
